# Construction QC Analytics

An interactive quality-control dashboard for a construction contractor, built around the work of a QA/QC manager: three-phase inspections, deficiency and corrective-action tracking, subcontractor performance, material conformance to approved submittals, and testing results.

**Live dashboard:** https://YOUR-GITHUB-USERNAME.github.io/construction-qc-analytics/

> **Data note:** all data is synthetic, generated by `scripts/generate_data.py` with a fixed random seed. Projects and subcontractors are fictional. The point of the project is the analysis and reporting, not real-world findings.

## What it answers
- Which subcontractors should be escalated at the next weekly QC meeting, and why?
- How do preparatory, initial and follow-up inspections compare on first-pass rate?
- How many corrective actions are open, how old are they, and how many are overdue?
- Are deliveries matching approved submittals, and why are they rejected?
- How are testing results trending?

## Key definitions
- **First-pass rate:** inspections that passed with no comments, divided by all inspections.
- **Overdue corrective action:** deficiency with no close date and a due date before the report date (Oct 31, 2026).
- **Escalation rule:** Escalate if first-pass is under 60% or 3 or more actions are overdue. Watch if under 70% or any overdue. Otherwise On track.

## Repository
| Path | Contents |
|---|---|
| `index.html` | Interactive dashboard (project filter, KPIs, scorecard). Works as a GitHub Pages site. |
| `data/` | Six CSVs (projects, subcontractors, inspections, deficiencies, material_receipts, test_results) and a SQLite copy, `qc.db` |
| `sql/queries.sql` | Six queries: first-pass by phase, subcontractor scorecard, deficiency aging, overdue actions, opened vs closed by month, rejected material reasons |
| `powerbi/measures.dax` | DAX measures and relationships for rebuilding the report in Power BI |
| `scripts/generate_data.py` | Regenerates the dataset (run from the repository root) |

## Run it
- **Dashboard:** open `index.html` in a browser.
- **SQL:** open `data/qc.db` in any SQLite tool and run the queries in `sql/queries.sql`.
- **Power BI:** load the CSVs, relate fact tables to `projects` on `project_id` and to `subcontractors` on `sub_id`, then add the measures from `powerbi/measures.dax`.
- **Regenerate data:** `python scripts/generate_data.py`

## Skills shown
SQL (CTEs, joins, aggregation), Power BI and DAX, KPI design, data modeling, dashboard design, and construction QC concepts such as inspection phases, deficiency tracking and submittal conformance.
